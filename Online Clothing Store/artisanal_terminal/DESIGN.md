## Brand & Style

This design system embodies the disciplined tactility of deliberate software engineering. Rejecting ephemeral trends, over-saturated neon hues, and generic algorithmic glassmorphism, it reflects an authentic, workshop-hewn aesthetic tailored for a senior frontend systems architect. The visual identity operates at the intersection of a master woodworker's joinery and precision-calibrated bench instrumentation.

The target audience comprises discerning engineering directors, technical founders, and product craftspeople who value substance, typographic tension, and bespoke structural discipline. The interface evokes quiet mastery, focus, and permanent durability. 

The aesthetic is grounded in **Technical Brutalism refined by Warm Minimalism**: strict structural planes, calibrated hairline divisions, intentional monospaced metrics, and tactile feedback loops rooted in mechanical switches and archival hardware rather than synthetic glowing cards.

## Colors

The palette draws from deep mineral charcoal, soot, raw vulcanite, and aged brass hardware. It rejects cold, clinical blue-grays in favor of an organic, thermally balanced dark spectrum.

### Surface System
- **Base Canvas (`#0c0d0e`)**: Deep obsidian-graphite with a slight thermal cast, preventing visual fatigue across extended reading sessions.
- **Surface Elevation 1 (`#141618`)**: Layered architectural panels, code frames, and primary card enclosures.
- **Surface Elevation 2 (`#1a1d20`)**: Interactive triggers, table rows, and secondary navigation docks.
- **Surface Interactive / Hover (`#22262a`)**: Feedback tone for active selections and hovered inputs.

### Brass & Amber Accent System
- **Core Technical Amber (`#d97706`)**: Structural accent for interactive indicators, git status markers, and deliberate callouts.
- **Brass Light (`#f59e0b`)**: Focus halos, hover thresholds, and compiler success tokens.
- **Aged Brass Highlight (`#fbbf24`)**: High-priority micro-badges, commit hashes, and active metrics.
- **Muted Amber Wash (`rgba(217, 119, 6, 0.08)`)**: Subdued background fill for highlighted code blocks, tags, and inline callouts.

### Neutral & Typographic Spectrum
- **Bone White (`#f4f4f5`)**: Primary headlines and core typographic data.
- **Parchment Gray (`#e4e4e7`)**: Secondary body copy, code body, and descriptive labels.
- **Muted Steely Zinc (`#a1a1aa`)**: Secondary metadata, timestamps, and breadcrumb divisions.
- **Subtle Hairline Border (`rgba(244, 244, 245, 0.08)`)**: Utilitarian, precision-etched borders across all panels.
- **Warm Hairline Border (`rgba(217, 119, 6, 0.22)`)**: Deliberate focal bounding boxes for active cards and code inspections.

## Typography

The typographic hierarchy pairs the hyper-clean proportional geometric architecture of **Geist** with the exact, calculated legibility of **JetBrains Mono**.

### Typographic Principles
- **Intentional Contrast**: Headings use tight negative letter-spacing to yield a crisp, print-editorial density. JetBrains Mono is deployed purposefully for indices, technical parameters, file trees, commit metadata, and status badges.
- **Tabular Figures**: Numeric data, timelines, and metrics must strictly utilize tabular figures (`font-variant-numeric: tabular-nums`) to preserve optical alignment across architectural diagrams and project logs.
- **Editorial Legibility**: Body copy maintains an intentional line-height of 1.6 to 1.65 to ensure extended case studies and architectural post-mortems read with the clarity of a physical monograph.

## Layout & Spacing

The layout is constructed on an intentional 12-column fixed-max system with strict rhythmic constraints:
- **Max Content Bounding Box**: 1180px, centered with deterministic side margins.
- **Desktop (1024px+)**: 12 columns, 24px (`1.5rem`) gutters, 48px (`3rem`) page margins.
- **Tablet (768px - 1023px)**: 8 columns, 20px gutters, 32px page margins.
- **Mobile (< 768px)**: 4 columns, 16px (`1rem`) gutters, 20px (`1.25rem`) canvas inset.

### Section Architecture
Layout sections follow a rigorous horizontal datum line. Content panels separate via continuous 1px rules rather than empty, adrift expanses of whitespace. Spacing rhythm enforces structural integrity: structural card interiors adhere strictly to `space-md` or `space-lg`, while code blocks and technical lists lock to `space-sm` increments.

## Elevation & Depth

This system intentionally excludes fuzzy drop shadows, blurry diffusion fields, and iridescent glows. Visual hierarchy and layering are communicated exclusively through **material elevation tiers and high-precision hairline borders**.

### Structural Tiers
1. **Ground Zero (`#0c0d0e`)**: The global viewport canvas.
2. **Structural Tier 1 (`#141618`)**: Primary modules, project tiles, and structural workbench columns. Border: `1px solid rgba(244, 244, 245, 0.08)`.
3. **Structural Tier 2 (`#1a1d20`)**: Embedded terminal consoles, filter toggles, tooltips, and sub-panels. Border: `1px solid rgba(244, 244, 245, 0.12)`.
4. **Active/Focus State**: Outlined with `1px solid rgba(217, 119, 6, 0.45)`, coupled with an optional tight, non-diffused keyline: `box-shadow: 0 0 0 1px #d97706`.

### Mechanical Depth
Interactive depth is conveyed via discrete tactile translation rather than atmospheric lifting. Buttons shift downwards by 1px on click (`transform: translateY(1px)`) rather than expanding blurred drop-shadows. Surfaces are matte, flat, and crystalline in their delineation.

## Shapes

The design system enforces a disciplined **Soft Precision** radius philosophy (`level 1`):
- **Base Components (Inputs, Buttons, Badges)**: 4px (`0.25rem`) corner radius. Maintains crisp geometric discipline while softening abrasive brutalist corners.
- **Structural Modules & Containers (`rounded-lg`)**: 8px (`0.5rem`) corner radius. Applied to major case-study containers, modal dialogues, and terminal windows.
- **Hero Windows & Floating Docks (`rounded-xl`)**: 12px (`0.75rem`) maximum radius.
- **Status Indicators & Micro-Pills**: Small circular points or 2px micro-radii. Pill buttons (`9999px`) are explicitly prohibited to prevent consumer-SaaS dilution.

## Components

### Buttons & Interactive Triggers
- **Primary Button**: Background `#d97706`, foreground `#0c0d0e`, font JetBrains Mono 12px weight 600 with uppercase transformation. 4px corner radius, padding `0.5rem 1rem`. Hover state shifts background to `#f59e0b`. Active state shifts down 1px.
- **Secondary / Mechanical Trigger**: Background `#141618`, foreground `#f4f4f5`, 1px border `#2a2e33`. Hover: border `#d97706`, text `#fbbf24`.
- **Ghost Action**: Monospaced text with an explicit trailing symbol (e.g., `view_project ->`), underlined with an amber hairline with 4px underline offset.

### Badges & Technical Chips
- Constructed with JetBrains Mono (11px, weight 500, uppercase).
- Structure: 1px border in `rgba(217, 119, 6, 0.25)`, background `rgba(217, 119, 6, 0.06)`, text `#fbbf24`.
- Accompanied by a square 4px status tick or dot rendered in `#d97706`.

### Project Cards & Dossiers
- Background `#141618`, border `1px solid rgba(244, 244, 245, 0.08)`, radius 8px.
- Padding: 24px (`space-lg`).
- Structure: Header row housing monospaced project metadata, index (e.g., `01 // ARCHITECTURE`), and deployment timestamp; followed by headline and summary; terminating with a strict hairline divider and a list of architectural constraints.
- Hover behavior: Hairline border transitions to `rgba(217, 119, 6, 0.4)`. Zero blur elevation.

### Terminal & Code Blocks
- Enclosed in an explicit framed box with a custom command strip (`zsh`, branch indicators, copy-to-clipboard action).
- Background `#101214`, inset padding `16px 20px`.
- Line numbering rendered in `#52525b`, code body in `#e4e4e7`, amber syntax emphasis for functions and keys.

### Form Inputs & Filters
- Background `#0c0d0e`, 1px border `rgba(244, 244, 245, 0.12)`, radius 4px.
- Focus: Border snaps to `#d97706` without generic blue halos.
- Typography: JetBrains Mono 13px with placeholder text in `#52525b`.

### Checkboxes & Segmented Radios
- Box size: 14x14px square, radius 2px, 1px border `#52525b`. Checked state features a solid amber `#d97706` core with a dark check icon.
- Segmented matrix toggles: Fixed height, flush layout separated by 1px vertical borders in `#1e2226`. Selected tab receives surface `#22262a` with an amber top-edge border indicator.
