# Mahmoud AbuSaeda — Portfolio

موقع معرض أعمال ثابت مبني باستخدام HTML وCSS وJavaScript، ولا يحتاج إلى تثبيت حزم أو خطوة بناء.

## تشغيل الموقع محليًا

افتح `index.html` في المتصفح، أو شغّل خادم ملفات ثابتة من مجلد المشروع. استخدم خادمًا محليًا عند اختبار أي ميزات تعتمد على طلبات الشبكة.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
2. افتح **Settings → Pages** في المستودع.
3. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واضغط **Save**.
4. انتظر اكتمال النشر وافتح الرابط الذي يظهر في صفحة Pages.

`index.html` هي الصفحة الرئيسية المطلوبة لـ GitHub Pages. بقي `code.html` كإعادة توجيه للتوافق مع روابط المشاريع الحالية. ملف `.nojekyll` يعطل معالجة Jekyll الافتراضية، ولا يتطلب الموقع أي إعداد بناء.

## محتويات المجلد

- `index.html` و`styles.css` و`script.js`: الموقع الرئيسي.
- `img/`: صور الموقع الرئيسية.
- `Sign/`, `Films/`, `Resturant/`, و`Online Clothing Store/`: نماذج المشاريع المستقلة ولقطات المعاينة الخاصة بها.
- `portfolio-branding.js` و`portfolio-branding.css`: عناصر الهوية المشتركة لصفحات المشاريع.
- ملفات `DESIGN.md`: ملاحظات التصميم لكل مشروع.

تستخدم بعض صفحات النماذج خطوطًا أو صورًا أو Tailwind CSS من خدمات خارجية؛ يلزم اتصال بالإنترنت لظهور هذه الموارد.
